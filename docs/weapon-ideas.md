# Eigen

Implemented in v0.25.0 with the user-approved name. Nine native untargetable energy orbs per owner, hold-to-direct and release-to-recall controls, staggered initial deployment, three-second replacements, 24-tile reach, up to double damage on active swipes, curved orb trails, per-tier contact-energy budgets/damage and a four-point cost. See README.md and implementation-notes.md for current mechanics and validation. Future balance changes should use ordinary moving-target/wave playtests.
