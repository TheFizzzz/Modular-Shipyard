# Modular Shipyard

Customize your core ship's weapons, colours and stats, and save your favourite builds as loadouts. Currently supports Serpulo's Alpha, Beta and Gamma; Erekir support is planned.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3828762721)

## Installation (non-Steam)

Requires desktop Mindustry **v160.2 or newer**.

1. Open the [builds page](https://github.com/TheFizzzz/Modular-Shipyard/actions/workflows/build.yml) and select the latest successful run.
2. Download the **modular-shipyard-desktop** artifact at the bottom of that run's page. GitHub sign-in is required.
3. Extract the downloaded ZIP to get `modular-shipyardDesktop.jar`.
4. In Mindustry, open **Mods → Import Mod → Import File**, select the JAR, and restart the game.

For multiplayer, the host and all players need the same mod version.
